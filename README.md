# 📝 AI Resume Optimizer — ATS-Friendly Resume Builder

**AI analyzes, enhances, and formats your resume. Beat ATS filters. Land more interviews.**

## How It Works

```
Paste your resume → AI detects industry → Analyzes weak phrases → Suggests keywords → Optimizes text → Outputs ATS-ready resume
```

## Features

- 🎯 **Industry Detection** — Auto-detects Tech, Finance, Marketing
- 🔑 **Keyword Optimization** — Adds missing ATS keywords for your industry
- ✏️ **Weak Phrase Replacement** — "Responsible for" → "Led / Engineered"
- 📊 **Scoring** — Before/after resume score (0-95)
- 📏 **Length Check** — Optimal 300-800 words
- 📈 **Metrics Detection** — Ensures you have quantified achievements
